# Phase 1 — UI Design Contract

> Visual and interaction contract for the auth & foundation phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Scope: Sign-up screen (email + password + username), sign-in screen, password reset screen, post-signup onboarding screen, and session-expired redirect message. Web (Next.js) only for this phase — mobile auth screens follow the same tokens via NativeWind.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (official registry, default theme — to be initialized at project scaffold) |
| Preset | Default shadcn preset — no custom preset string; developer will run `npx shadcn init` at scaffold time |
| Component library | Radix UI (via shadcn) |
| Icon library | lucide-react (bundled with shadcn default install) |
| Font — Display | Fraunces (Google Fonts, variable, axes: opsz wght SOFT WONK) |
| Font — Body / Labels | Inter (Google Fonts, variable, axis: wght) |

**Font loading (Next.js):**

```typescript
// apps/web/app/layout.tsx
import { Fraunces, Inter } from 'next/font/google'

const inter = Inter({
  subsets: ['latin'],
  variable: '--font-inter',
  display: 'swap',
})

const fraunces = Fraunces({
  subsets: ['latin'],
  variable: '--font-fraunces',
  axes: ['opsz', 'SOFT', 'WONK'],
  display: 'swap',
})
```

Apply `inter.variable fraunces.variable` to the `<html>` element. Reference via `font-[family-name:--font-fraunces]` and `font-[family-name:--font-inter]` in Tailwind v4.

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, helper text margin-top, inline badge padding |
| sm | 8px | Input label to input gap, button icon to label gap |
| md | 16px | Default field spacing, card internal padding (horizontal) |
| lg | 24px | Between form fields, card internal padding (vertical) |
| xl | 32px | Between form sections, heading to form gap |
| 2xl | 48px | Auth card top/bottom padding on desktop |
| 3xl | 64px | Page-level vertical centering offset |

Exceptions:
- Touch targets on mobile: minimum 44px height for all interactive elements (tap area), even if visual height is smaller. Achieve via `min-h-[44px]` with `flex items-center`.
- Auth card max-width on web: 400px (hardcoded, not a spacing token).

## Typography

| Role | Font | Size | Weight | Line Height | Usage |
|------|------|------|--------|-------------|-------|
| Body | Inter | 16px | 400 (Regular) | 1.5 | Form helper text, body copy on onboarding screen |
| Label | Inter | 14px | 400 (Regular) | 1.4 | Input field labels, nav links, small metadata |
| Heading | Fraunces | 20px | 600 (SemiBold) | 1.2 | Card section headings, onboarding section title |
| Display | Fraunces | 32px | 600 (SemiBold) | 1.15 | Auth screen main heading ("Welcome to Lunchboxd", "Sign in"), app wordmark |

Rules:
- Body and Label use Inter exclusively. Fraunces is reserved for Heading and Display roles only.
- No font size outside this set of four is permitted in Phase 1 screens.
- All text color defaults to `--color-text-primary` (`#1C1917`) unless specified as secondary or on-accent.
- Error/helper text under inputs: 14px Inter 400 (Label size, regular weight).

## Color

| Role | Hex | Tailwind Custom Token | Usage |
|------|-----|-----------------------|-------|
| Background (60%) | `#FFF8F0` | `--color-bg` | Page background, auth screen backdrop |
| Surface (30%) | `#FFF0E0` | `--color-surface` | Auth card background, input field backgrounds |
| Accent (10%) | `#F97316` | `--color-accent` | See reserved list below |
| Text primary | `#1C1917` | `--color-text-primary` | All headings, body text, input text |
| Text secondary | `#78716C` | `--color-text-secondary` | Helper text, placeholder text, supporting copy |
| Border | `#E7D5C5` | `--color-border` | Input borders (default state), card borders, dividers |
| Destructive | `#EF4444` | `--color-destructive` | Destructive actions and their confirmation UI only |

**Accent reserved for (exhaustive list):**
1. Primary CTA button background ("Create account", "Sign in", "Continue") — text on accent is white (`#FFFFFF`)
2. Focus ring on interactive elements (inputs, buttons, links) — 2px solid ring, 2px offset
3. App wordmark / logo mark color
4. Hover state underline on text links (sign-in link, "Forgot password?" link)
5. Secondary button hover border — border shifts to `#F97316` on hover

Accent is NOT used on: secondary buttons (default state), card borders, icons in their default state, background fills, or any neutral UI chrome.

**Input state colors:**

| State | Border | Background |
|-------|--------|------------|
| Default | `#E7D5C5` (`--color-border`) | `#FFF0E0` (`--color-surface`) |
| Focus | `#F97316` (`--color-accent`) 2px ring | `#FFF0E0` |
| Error | `#EF4444` (`--color-destructive`) | `#FFF0E0` |
| Disabled | `#E7D5C5` at 50% opacity | `#FFF8F0` |

**Secondary button style:** Outlined — border `#E7D5C5`, background transparent, text `#1C1917`. Hover: border shifts to `#F97316`, text unchanged.

## Component Contract

### Auth Card (shared layout wrapper)

All auth screens (sign-up, sign-in, forgot password) use this card:

- Max-width: 400px, centered horizontally and vertically on page
- Background: `--color-surface` (`#FFF0E0`)
- Border: 1px solid `--color-border` (`#E7D5C5`)
- Border-radius: 12px (Tailwind `rounded-xl`)
- Padding: 48px vertical, 32px horizontal (desktop); 24px all sides (mobile, full-width)
- Box-shadow: `0 1px 4px 0 rgba(28, 25, 23, 0.08)` — subtle warm shadow

Above the card: App wordmark in Fraunces Display 32px SemiBold (600), `#F97316`, centered. No separate logo image in Phase 1 — wordmark text only.

### Input Fields (shadcn `Input` component, customized)

- Height: 44px (satisfies touch target minimum)
- Font: Inter 16px 400
- Placeholder color: `--color-text-secondary` (`#78716C`)
- Label above input: Inter 14px 400, `--color-text-primary`, margin-bottom 8px
- Helper/error text below: Inter 14px 400, `--color-text-secondary` (helper) or `--color-destructive` (error), margin-top 4px
- Username field: prefix display of `@` in `--color-text-secondary` inside the input left edge (not a separate element — inline prefix pattern)

### Primary Button (shadcn `Button` variant="default", customized)

- Background: `#F97316`
- Text: `#FFFFFF`, Inter 16px 600
- Height: 44px, full-width within card
- Border-radius: 8px (`rounded-lg`)
- Hover: background `#EA6C10` (10% darker orange)
- Active: background `#D96209`
- Disabled: 50% opacity, cursor not-allowed
- Loading state: spinner (lucide-react `Loader2` icon, `animate-spin`) replaces label text; button stays full-width and disabled

### Secondary / Ghost Button (shadcn `Button` variant="outline")

- Used for: "Sign in with Google" button
- Border: 1px solid `--color-border`
- Background: transparent
- Text: `#1C1917`, Inter 16px 600
- Height: 44px, full-width
- Prefix: Google `G` logo SVG (inline, 20px) — not from icon library, inline SVG per standard OAuth button spec
- Hover: border-color `#F97316`

### Divider with label

Between password sign-up and Google OAuth: horizontal rule with centered "or" text. Tailwind: `flex items-center gap-4` with `<hr class="flex-1 border-[--color-border]">` on each side and `<span class="text-[14px] text-[--color-text-secondary] font-inter">or</span>` center.

### Onboarding Screen (post-signup `/welcome`)

- No auth card container — full-page layout
- Background: `--color-bg` (`#FFF8F0`)
- Heading: Fraunces Display 32px SemiBold (600) — "Welcome to Lunchboxd, @{username}"
- Body: Inter 16px 400 — short explainer (2 sentences max, see Copywriting Contract)
- Two CTA buttons stacked vertically, max-width 320px, centered:
  1. Primary (accent): "Log your first meal"
  2. Secondary (outline): "Find friends to follow"
- Spacing between CTAs: 8px (sm token)

| Session expired message | "Your session expired. Please sign in again." — displayed as a banner at the top of the sign-in card (amber background `#FEF3C7`, text `#92400E`, lucide `AlertCircle` icon 16px, dismissible) |

| Validation — required field | "This field is required." |

| Password reset success | "Check your email — we sent a reset link to {email}." |
| Generic API error | "Something went wrong. Please try again." |

**Voice notes:**
- Warm, direct, minimal. No exclamation marks on error states.
- Never say "Invalid credentials." — say "Email or password is incorrect." (specific, human)
- "Log" is the primary verb for the core action throughout the app. Establish it here.

## Interaction Contract

### Form Submission

- Validation fires on blur per field (not on submit only)
- Submit button shows loading spinner immediately on click; re-enables only on server error response
- On success: client-side navigation (no full page reload) — use Next.js `router.push`

### Focus Management

- On page load: first field (email on sign-in, username on sign-up) receives focus via `autoFocus`
- On error response: focus moves to the first errored field
- Focus ring: 2px solid `#F97316`, 2px offset, border-radius matches element

### Link navigation within auth screens

| Link | Location | Destination |
|------|----------|-------------|
| "Sign in" | Sign-up screen, below CTA | `/sign-in` |
| "Create account" | Sign-in screen, below CTA | `/sign-up` |
| "Forgot password?" | Sign-in screen, below password field | `/forgot-password` |
| "Back to sign in" | Forgot password screen | `/sign-in` |

Link style: Inter 14px 400, color `--color-text-secondary`, hover: underline + color `#F97316`. No underline by default.

### Accessibility Minimums

- All inputs: `aria-label` or visible `<label>` with `htmlFor` — no placeholder-only labeling
- Error messages: `role="alert"` so screen readers announce them on inject
- Buttons in loading state: `aria-disabled="true"` and `aria-label="Loading..."` replaces label
- Color is never the sole indicator of state — error inputs also show an error icon (lucide `AlertCircle` 16px, `--color-destructive`) inside the input right edge
- Minimum contrast: all text on surface (`#1C1917` on `#FFF0E0`) exceeds WCAG AA 4.5:1
