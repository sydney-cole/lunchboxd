## What Was Built

### Schema Changes

- **`apps/web/lib/schema.ts`**: Added `mealDate: date('meal_date')` column to the `reviews` table between `photoUrl` and `deletedAt`. Added `restaurantsPlaceIdIdx` partial unique index on `restaurants.placeId` using `WHERE place_id IS NOT NULL` to prevent duplicate Google Places IDs while allowing multiple manual entries with `NULL` place_id.

- **`apps/web/drizzle/0001_deep_tigra.sql`**: Migration file generated by `drizzle-kit generate` containing two statements: `ALTER TABLE "reviews" ADD COLUMN "meal_date" date` and `CREATE UNIQUE INDEX "restaurants_place_id_idx" ON "restaurants" USING btree ("place_id") WHERE place_id IS NOT NULL`.

### Shared Package Contracts

- **`packages/shared/src/schemas/index.ts`**: Added `reviewSchema` (mealType enum, optional half-star rating 0.5–5 in 0.5 increments, optional note max 2000 chars, optional tags array with per-tag max 50 chars, optional mealDate in YYYY-MM-DD format), `CreateReviewInput` type, `restaurantSearchSchema` (q min 2 chars), and `RestaurantSearchInput` type.

- **`packages/shared/src/types/index.ts`**: Added `mealDate: string | null` field to the `Review` interface.

### Wave 0 Test Stubs

- **`apps/web/__tests__/reviews.test.ts`**: Describe blocks for REVW-01 through REVW-07. Schema-validation tests (REVW-01,02,04,05) pass green. Photo (REVW-03) and API tests (REVW-06,07) are `it.todo()` stubs.
