## Spacing Scale

Declared values — sourced from `packages/shared/src/constants/tokens.ts` (locked, shared web + mobile):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline padding (e.g. author row avatar→text gap) |
| sm | 8px | Compact element spacing (e.g. tag list gap, like row gap) |
| md | 16px | Card body padding, feed list item horizontal padding |
| lg | 24px | Section vertical spacing, page top padding |
| xl | 32px | Display heading margin |
| 2xl | 48px | Empty state vertical centering offset |
| 3xl | 64px | Page-level vertical spacing on web |

Exceptions:
- Feed list gap between cards: 24px (lg) on web — matches existing reviews page `gap-6`
- Feed list gap between cards: 12px (sm + xs) on mobile — matches existing mobile card list style
- Author avatar size: 24px (w-6 h-6) on web ReviewCard author row — deliberately between xs and sm, matches RESEARCH.md Pattern 5 spec
- Author avatar size: 32px on mobile FeedCard author row — consistent with mobile card density
- FAB touch target: 56px diameter (fixed) — meets 44px minimum with margin; carried from Phase 2

## Typography

Source: `packages/shared/src/constants/tokens.ts` (locked); cross-referenced against existing component usage in `review-card.tsx`, `reviews/page.tsx`, `user-search-card.tsx`.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Label | 14px (fontSizes.label) | 400 regular | 1.5 | Review body text, tag list, date, author attribution line, like count |
| Body | 16px (fontSizes.body) | 400 regular | 1.5 | Subheadings, restaurant name in card, error/empty state body copy |
| Heading | 20px (fontSizes.heading) | 600 semibold | 1.2 | Page heading ("Feed"), empty state heading |
| Display | 32px (fontSizes.display) | 700 bold | 1.1 | Mobile app name display only — not used in feed phase |

Web fonts: Inter Variable for all label/body/heading roles; Fraunces reserved for brand moments (not used in feed cards).

Mobile: `StyleSheet.create()` with numeric fontSize values from `colors` / `fontSizes` tokens — NativeWind className not used (per STATE.md accumulated context: "Mobile components use StyleSheet.create() not NativeWind className").

## Color

Source: `apps/web/app/globals.css` `@theme` block and `packages/shared/src/constants/tokens.ts` (locked, shared).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8F0` (`bg`) | Page background — web `bg-bg`, mobile `colors.bg` |
| Secondary (30%) | `#FFF0E0` (`surface`) | Card backgrounds — web `bg-surface`, mobile `backgroundColor: colors.surface` equivalent |
| Accent (10%) | `#F97316` (`accent`) | See reserved list below |
| Destructive | `#EF4444` (`destructive`) | Liked heart fill state only in Phase 4 |

Accent (`#F97316`) reserved for:
1. FAB (floating action button) background
2. Like heart fill when `isLikedByMe === true` on web (via `text-destructive` — heart reuses destructive color per existing Phase 3 ReviewCard implementation; accent itself is not used for heart)
3. Focus rings on interactive elements (`focus:ring-accent`)
4. "Find people to follow" link in empty feed state
5. "Show more / Show less" text toggle within card body (existing pattern)
6. Hover border on cards (`hover:border-accent`)

Note: The liked heart uses `destructive` (#EF4444), not `accent` — this is the established pattern from Phase 3 `review-card.tsx`. Do not change.

Secondary semantic colors:
- `#78716C` (`textSecondary`) — author attribution text, tags, dates, counts — not an accent; a text tone
- `#E7D5C5` (`border`) — card borders, card divider lines
- `#FEF3C7` / `#92400E` (`sessionExpiredBg` / `sessionExpiredText`) — session expired banner only; not used in feed phase

## Interaction Contracts

### Author Row (ReviewCard — web, FeedCard — mobile)

- Rendered only when `showAuthor={true}` (web) or always on feed (mobile)
- Layout: `[avatar 24px circle] [@username · Xh ago]` on one row
- Avatar fallback: circle with first letter of username, `bg-accent/20` background, `text-accent font-medium text-[10px]`
- Separator: `border-b border-border pb-3 mb-3` below author row, above card content
- Relative time format: `just now` (< 1 min), `Xm` (< 1 hr), `Xh` (< 24 hr), `Xd` (< 7 days), `MMM D` (>= 7 days) — hand-rolled `formatRelativeTime()` utility, no library
- Author row is non-interactive in Phase 4 (no link to profile — Phase 5 scope)

### Kebab Menu (ReviewCard)

- Feed cards showing another user's reviews: kebab menu (`MoreHorizontal`) is hidden entirely — `onEdit` and `onDelete` props receive no-op functions or feed page does not render the menu
- Feed cards showing the current user's own reviews: kebab menu visible and functional (edit/delete work as normal)
- Decision: feed page must pass the current user's ID and the review's `userId` to determine visibility; or the feed API can include a `isOwnReview: boolean` field derived server-side

### Like Button (Feed)

- Like button present on all feed cards (both own and others' reviews)
- Feed like mutation targets `['feed']` query key, NOT `['my-reviews']` — separate optimistic update
- Optimistic update: toggle `isLikedByMe`, adjust `likeCount` by +1/-1 immediately
- On error: roll back to previous state from snapshot
- On settled: `invalidateQueries({ queryKey: ['feed'] })`
- Heart icon: `Heart` from lucide-react; filled with `fill-destructive text-destructive` when liked, outline when not
- Mobile: `Ionicons` `heart` / `heart-outline`; color `colors.destructive` (#EF4444) when liked, `colors.textSecondary` (#78716C) when not

### Infinite Scroll (Web)

- Sentinel `<div ref={sentinelRef}>` placed immediately after the last card in the list
- IntersectionObserver threshold: 0.1 (fires when 10% of sentinel enters viewport)
- Guard: only calls `fetchNextPage()` when `hasNextPage && !isFetchingNextPage`
- Footer loader: `<Loader2 size={20} className="animate-spin text-text-secondary mx-auto my-4" />` visible when `isFetchingNextPage`
- End of feed indicator: when `!hasNextPage && allItems.length > 0`, render `<p className="text-center text-[14px] text-text-secondary py-4">You're all caught up.</p>`
- No "Load more" button — infinite scroll only (per D-06)

### Pull-to-Refresh (Mobile)

- FlatList `onRefresh` calls `refetch()` which resets to first page (TanStack Query `useInfiniteQuery` refetch behavior)
- `refreshing` prop bound to `isLoading || isFetching` — shows native RefreshControl spinner
- `onEndReached` calls `fetchNextPage()` guarded by `hasNextPage && !isFetchingNextPage`
- `onEndReachedThreshold`: 0.3 (fires when 30% of list from bottom is reached)
- `ListFooterComponent`: `<ActivityIndicator color={colors.accent} />` when `isFetchingNextPage`, else `null`

### Web Auth Protection

- Feed page lives at `apps/web/app/(app)/page.tsx` (inside the `(app)` route group)
- `(app)/layout.tsx` already guards with `await auth()` + redirect to `/sign-in?expired=true`
- The default scaffold `apps/web/app/page.tsx` must be deleted or replaced with a redirect to `/(app)` equivalent — `(app)/page.tsx` takes root `/` automatically when `app/page.tsx` is removed

### Window Focus Refetch (Web)

- TanStack Query default: `refetchOnWindowFocus: true` — feed silently refetches when user returns to tab
- No explicit polling or interval — per D-09
- `staleTime: 60_000` — matches established pattern from `['my-reviews']` and `['user-search']` queries
