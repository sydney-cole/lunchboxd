# Quick Task 260710-a01 — Make the web app mobile-friendly

## Description

The Lunchboxd web app (mobile Expo app was stripped in 260429-a01, so this is web-only)
renders a desktop-only top navigation that breaks on phone-width screens. Make the app
usable on small screens.

## Problem (audit)

- **Top nav** (`app/(app)/layout.tsx`): three-column bar with fixed `w-44` side columns
  (176px each) + centered text links. On <640px viewports the columns overflow and the
  links crowd. This is the primary breakage.
- **Notification dropdown** (`notification-bell.tsx`): fixed `w-[380px]` anchored `right-0`
  to the bell — overflows the left edge of narrow screens.
- **Map page** (`map/page.tsx`): `h-[calc(100vh-64px)]` assumes only the 64px top nav; a
  mobile bottom bar would cover the list panel, and the stacked (column) layout gives the
  list no scrollable height.
- **FAB** (`floating-action-button.tsx`): fixed bottom-right — would overlap a bottom tab bar.
- **Review card** (`review-card.tsx`): fixed 148px image crowds text at ~320px.
- Pages (feed, reviews, profile, search, restaurant, composer) already use
  `max-w-[...] mx-auto px-4` and are responsive; they only need bottom clearance for the
  new bottom bar.

## Approach

1. **New `mobile-nav.tsx`** (client): fixed bottom tab bar, `md:hidden`, 5 tabs —
   Feed, Search, New (+, accent), Map, Profile (`/@username`). Active state via
   `usePathname`. Safe-area bottom padding via `env(safe-area-inset-bottom)`.
2. **`layout.tsx`**: keep the desktop top bar (`md:` breakpoint) but on mobile drop the
   fixed side widths, hide the centered links, keep logo + bell + avatar. Render
   `<MobileNav>`. Wrap `{children}` so normal scroll pages get bottom padding
   (`pb-[…] md:pb-0`) clearing the tab bar. Add `viewport` export with
   `viewportFit: 'cover'` so safe-area insets resolve on notched phones.
3. **`notification-bell.tsx`**: on mobile position the panel `fixed` with left/right
   gutters; keep the original desktop `absolute right-0` dropdown at `md:`.
4. **`map/page.tsx`**: mobile height subtracts top + bottom bars (`100dvh`); give the map a
   fixed portion and the list panel a scrollable `flex-1 min-h-0` region.
5. **`floating-action-button.tsx`**: `hidden md:flex` (New lives in the bottom bar on mobile).
6. **`review-card.tsx`**: image `w-[116px] sm:w-[148px]`.

## Verification

- `pnpm --filter web typecheck` (or `tsc --noEmit`) passes.
- `pnpm --filter web build` compiles.
- Desktop layout (≥ md) visually unchanged.
